# G1Pilot: Driving the Unitree G1 Humanoid with ROS 2

![G1Pilot]({{ site.baseurl }}/_images/g1pilot.png){: .align-center style="max-width: 700px;"}

[G1Pilot](https://github.com/hucebot/g1pilot) is an open-source ROS 2 package for controlling the **Unitree G1** humanoid robot. It sits on top of Unitree's built-in locomotion controller and adds a full custom stack for upper-body manipulation, teleoperation, and autonomous navigation — turning the G1 into a research-ready platform without reinventing the low-level walking control.

The project is maintained by **Clemente Donoso (INRIA)** and released under the **BSD-3-Clause** license.

---

## Dual-Controller Design

The central idea in G1Pilot is a clean separation of concerns:

- **Locomotion** is delegated to Unitree's native controller for walking and balancing, accessed through a `loco_client` interface.
- **Manipulation** is handled by a custom `arm_controller` that supports both **joint-level** (per-motor) and **Cartesian** (end-effector) control, switchable in real time.

This lets researchers focus on the parts they want to customize — arms, hands, navigation — while relying on Unitree's proven balance and gait control underneath.

---

## Key Capabilities

### Manipulation
- Joint and Cartesian arm control, switchable on the fly
- RViz **interactive markers** for precise end-effector positioning
- **DEX3 hand** control (open/close) via a dedicated controller

### Teleoperation
- Joystick-based teleoperation with real-time mode switching
- A command **multiplexer** (`joy_mux`) that arbitrates between manual teleoperation and autonomous control

### Navigation
- **MOLA** odometry for state estimation
- A custom **Dijkstra path planner** with look-ahead smoothing
- 2D occupancy grid generation for obstacle avoidance
- Nav2 integration for point-to-point autonomous locomotion

### Telemetry & Visualization
- Continuous publishing of IMU data, odometry, and per-motor feedback — including **temperature and voltage**
- Pre-configured URDF models and RViz setup for immediate robot-state visualization

## Node Architecture

G1Pilot is built from a dozen specialized ROS 2 nodes, including:

| Node | Role |
|------|------|
| `robot_state` | Publishes joint positions, velocities, efforts, motor temperature and voltage |
| `arm_controller` | Upper-body control in joint and Cartesian modes |
| `loco_client` | Interfaces with Unitree's locomotion controller |
| `interactive_marker` | RViz-based end-effector position/orientation control |
| `joystick` / `joy_mux` | Teleoperation input and command multiplexing |
| `dijkstra_planner` | Path planning with look-ahead smoothing |
| `mola_fixed` | MOLA odometry interface and frame transforms |
| `dx3_controller` | DEX3 hand control |
| `nav2point` / `create_map` | Navigation stack integration and occupancy grid generation |
| `ui_interface` | Primary control interface for robot functionality |

## Hardware & Software Targets

- **Robot**: Unitree G1 humanoid with the DEX3 hand
- **Sensors**: Livox LiDAR, RealSense depth cameras
- **Platform**: Ubuntu 22.04, ROS 2 Humble/Jazzy
- **Connection**: Ethernet-based robot communication

---

## Docker-First Deployment

The project takes a **Docker-first** approach for reproducible builds. Separate images are built for the teleoperation station and the robot using the provided `build.sh` and `run.sh` scripts. Once the workspace is sourced, dedicated launch files bring up individual stacks:

- `bringup_launcher.launch.py` — complete system startup
- `navigation_launcher.launch.py` — autonomous locomotion
- `manipulation_launcher.launch.py` — arm control
- `teleoperation_launcher.launch.py` — remote operation
- `livox_launcher.launch.py` / `mola_launcher.launch.py` — LiDAR and odometry

---

## Why It Matters

Humanoid platforms like the Unitree G1 are increasingly accessible, but bridging a vendor's closed locomotion controller with a flexible, ROS 2-native research stack is non-trivial. G1Pilot provides exactly that bridge: proven walking underneath, and an open, modular layer for manipulation, teleoperation, and navigation on top — a solid starting point for anyone doing humanoid research on the G1.
